# 🏎️ README – GP DE SÃO PAULO | PITWALL


## 📌 Descrição do Projeto

O PITWALL é um site desenvolvido com o tema do Grande Prêmio de São Paulo de Fórmula 1. O objetivo é apresentar informações sobre os pilotos, classificação da corrida e venda de ingressos para o evento no Autódromo de Interlagos.

## 💻 Tecnologias Utilizadas

- **HTML5:** Estruturação das páginas e conteúdos do site.
- **CSS3:** Estilização, cores, organização dos elementos e layout.
- **Google Fonts:** Utilização da fonte Titillium Web.

## ⚙️ Funcionalidades

- **Página inicial:** Apresenta o GP de São Paulo e informações sobre o circuito.
- **Grid de pilotos:** Exibe alguns pilotos e suas respectivas equipes.
- **Classificação:** Apresenta posições, voltas, diferenças e pontuação dos pilotos.
- **Pesquisa e filtros:** Campos para pesquisar pilotos e selecionar equipes.
- **Ingressos:** Apresenta setores disponíveis e seus respectivos preços.
- **Formulário de reserva:** Permite preencher dados pessoais, escolher a data, quantidade e setor dos ingressos.

## 🎨 Design

O site possui um visual inspirado no automobilismo e na Fórmula 1, utilizando cores, elementos e organização visual que remetem às pistas de corrida e às equipes.

## 🎯 Objetivo

Desenvolver um site temático utilizando conhecimentos de HTML5 e CSS3, trabalhando com estruturação de páginas, formulários, tabelas, links e estilização.
